# skill_docs

Artifacts produced by the [DataHub Claude skills](https://docs.datahub.com/docs/metadata-ingestion/datahub-skills).
DataHub asks contributors to commit these alongside the source so reviewers can see the
reasoning behind the connector, not just the result.

| File | Produced by | Status |
| --- | --- | --- |
| `QUALYTICS_PLANNING.md` | `/datahub-connector-planning` | ✅ Phase 1, 2026-09-09 |
| `PR_REVIEW.md` | `/datahub-connector-pr-review` | ✅ 2026-09-10; re-review 2026-10-06 |

**`QUALYTICS_PLANNING.md` is the authoritative entity mapping**, written against the captured
OpenAPI spec rather than from memory. Both documents are development records: they keep
the corrections made along the way, because the reasons behind a design are what a
reviewer most needs. `PR_REVIEW.md` is the 2026-10-06 re-review; the first review and
the live verification are summarised in its History section.
